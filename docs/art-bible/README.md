# Арт-біблія «Maze: Bunker-71» (MVP)

Обсяг за ST-01.3: мудборд бункера, палітра, 3 референси освітлення.
Мета: усі асети (свої, куплені, згенеровані) виглядають як одна гра.

## 1. Одне речення про стиль

> _Підземний модульний бункер 2031 року для надбагатих, який 3 тижні як
> перейшов у режим ізоляції: дороге, але зношене; чисті лінії панелей
> на рейках, техніка під стелею, аварійне світло._

Заповнити/уточнити: __________

## 2. Мудборд

Папка `moodboard/`, 20–40 зображень. Іменування: `NN_категорія_опис.jpg`.

| Категорія | Кількість | Що шукати |
|---|---|---|
| Референси з документа | 5–8 | «Бункер» (Silo), «Сховище 33», «Куб», «Платформа», S.T.A.L.K.E.R. |
| Реальні бункери | 5–8 | радянські бомбосховища, швейцарські цивільні сховища, дата-центри |
| Модульні стіни на рейках | 3–5 | серверні шафи, промислові розсувні перегородки, контейнерні модулі |
| Житло для багатих під землею | 3–5 | Survival Condo, Vivos, люксові яхти (тісно + дорого) |
| Знос і слід катастрофи | 3–5 | іржа на нержавійці, потьоки, зірвані панелі |
| Стеля з трубами | 3–5 | вентиляційні короби, кабель-канали, маркування труб кольором |

Заборонене (щоб не зʼїхати в чужий стиль): _мультяшність, фентезі,
стерильна sci-fi білизна без зносу._

## 3. Палітра

Заповнити hex після мудборду. Ігрова семантика кольорів обовʼязкова:
гравець має за кольором розрізняти безпеку, небезпеку і вихід.

| Роль | Колір | HEX | Де використовується |
|---|---|---|---|
| Основа стін | бетон / сіро-бежева панель | `#______` | панелі на рейках |
| Метал конструкцій | темна нержавійка, іржа | `#______` | рейки, труби, стелажі |
| Освітлення «день» | холодно-біле | `#______` | штатні світильники |
| Освітлення «ніч»/аварія | помаранчево-червоне | `#______` | режим ізоляції, сирена |
| Безпечна зона | тепле жовте / зелене | `#______` | стартовий бокс, сейф-кімната |
| Небезпека / заражені | | `#______` | плями, маркування закритих зон |
| Вихід (шлюз «Нуль») | червоний (спадок «червоної клітинки») | `#______` | двері шлюзу, покажчики |
| Акцент UI / HUD | | `#______` | наручний годинник, інвентар |

Правило: не більше 2 акцентних кольорів у одній кімнаті.

## 4. Освітлення: 3 референси

Папка `lighting/`, по одному зображенню + 3–5 рядків опису на кожен стан.

| Файл | Стан | Ігрова умова (з документа) | Настрій |
|---|---|---|---|
| `01_day.jpg` | Штатне «день» | розклад Архітектора 14 год | рівне, читається геометрія |
| `02_night_emergency.jpg` | Аварійне «ніч» | 10 год, видимість −40 %, більше заражених | контраст, глибокі тіні, мигання |
| `03_safe_room.jpg` | Безпечна кімната | стартовий бокс, сейф-кімната | тепле, тихе, «можна видихнути» |

## 5. Матеріали і масштаб (для сумісності з блокаутом)

- Клітинка 4 × 4 м, стіна 0,4 м, висота 3,2 м (розділ 7.1).
- Панель стіни: один модуль = одна клітинка, стик видимий (рейка).
- Текстури: 2 м = 1024 px (texel density ~5 px/см) для профілю Low.
- Тайлинг: панель, підлога, стеля з трубами: по 1 базовому матеріалу + 1 варіант зносу.

## Чекліст готовності арт-біблії

- [ ] Речення про стиль затверджене
- [ ] Мудборд: ≥ 20 зображень, усі категорії закриті
- [ ] Палітра: усі HEX заповнені, перевірено на дальтонізм (безпека vs небезпека vs вихід)
- [ ] 3 референси освітлення з описом
- [ ] Масштаб і texel density узгоджені з блокаутом (див. `blockout-checklist.md`)
