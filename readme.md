# Maze-Rase — Гонка в лабіринті

**Maze-Rase** — браузерна аркадна гра на чистому HTML, CSS і JavaScript. Два учасники (ви та комп’ютер) одночасно проходять **окремі** процедурно згенеровані лабіринти; перемагає той, хто першим дійде до виходу. Окрім гонки, є привиди, бонуси на карті, випадкові події та серія з 38 матчів із збереженням турнірної статистики.

## Основна ідея

Гравець і ШІ змагаються в паралель: на екрані два лабіринти 21×21, однакові правила, різні карти. Старт — зелена клітинка, фініш — червона. Стіни непрохідні. Комп’ютер використовує «розумний» пошук шляху; привиди можуть переслідувати, розмножуватися та змінювати поведінку, ускладнюючи забіг.

## Режими та сторінки

| Файл | Опис |
|------|------|
| `index.html` | **Головний режим** — гонка «гравець vs комп’ютер», два лабіринти, привиди, кирка, життя, турнір на 38 ігор |
| `global.html` | **Велика карта** (71×71) — один лабіринт, привиди, заручники, осинові кілки, кирка |
| `standings.html` | **Турнірна таблиця** — перемоги, очки та кількість ігор (дані з `localStorage`) |
| `test-mode.html`, `test-mode-experimental.html` | Тестові варіанти механік |
| `npc-ai.html`, `npc-ai-mini.html` | Режим **виживання** — лабіринт, зомбі, зброя, предмети, рівні |

Усі режими пов’язані навігаційним меню внизу сторінок.

## Ігрові механіки (головний режим)

- **Генерація лабіринту** — алгоритм recursive backtracking; карта щоразу нова.
- **Привиди** — 2–3 на кожній стороні, патруль і переслідування; при зіткненні учасник «спійманий».
- **Кирка** — з’являється на карті; дозволяє тимчасово ламати стіни.
- **Життя** — додаткові спроби після поразки від привидів.
- **Випадкові події** — зміни на карті під час матчу.
- **Турнір** — до 38 ігор між «Гравець» і «Комп’ютер»; рахунок зберігається в браузері.

## Керування

- **Рух:** стрілки ← ↑ ↓ → або **WASD**
- **Нова гра / пауза** — кнопки в інтерфейсі гри

## Технології

- Без збірки та залежностей — лише статичні файли
- Збереження турніру: **Web Storage** (`localStorage`)
- Підтримка сучасних браузерів з увімкненим JavaScript

## Для кого продукт

Для швидких офлайн-забігів у браузері, експериментів з ШІ в лабіринті та демонстрації процедурної генерації карт і поведінки NPC. Підходить як навчальний або розважальний проєкт без бекенду.
